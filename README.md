# Fujitsu AC Remote

Fujitsu Electric AC remote control for Flipper Zero.

![Screenshot](img/screenshot.png)

Available to download on the Flipper App Catalog [here](https://lab.flipper.net/apps/fujitsu_ac_remote)
## Building
```shell
# Clone repository
git clone https://github.com/achistyakov/flipperzero-fujitsu-ac-remote.git
cd fujitsu_ac_remote

# Build the application
ufbt build

# Build and launch the application
ufbt launch
```
